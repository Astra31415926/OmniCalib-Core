# OmniCalib-Core

Математическое ядро системы сквозной детерминированной калибровки цвета с открытым исходным кодом.

## Суть проекта
OmniCalib обеспечивает стопроцентную обратимость данных в цикле «Экран -> Печать -> Сенсор камеры -> Экран». Вместо классического сжатия спектра (ICC-профили), ядро оперирует инвариантной спектральной матрицей и принципом целостности каналов, используя физический «Камертон» и «Фиолетовый лимитер» для вычисления искажений среды.

## Структура MVP
- Сетка данных: 380–780 нм с шагом 10 нм (41 точка).
- Реальные спектральные кривые квантовой эффективности (QE) сенсоров.
- Архитектурный задел под нелинейную модель Кубелки — Мунка.
